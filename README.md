# Issey Siele Mechanical Engineering Portfolio

A static portfolio website.

## Files

- `index.html`: Home page
- `about.html`: About Me page
- `portfolio.html`: Portfolio page with case-study cards
- `project-rt300.html`: RT300 project page
- `project-warman.html`: Warman project page
- `contact.html`: Contact page
- `styles.css`: Main styling ("Drafting Studio" design system)
- `script.js`: Mobile menu, scroll-aware header, and scroll-reveal animations
- `assets/`: Images used by the site
